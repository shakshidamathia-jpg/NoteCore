# 📚 NoteCore

### Study Smarter. Revise Better. Crack Your Exam. 🎯

**NoteCore** is a modern, responsive digital notes platform built for students preparing for competitive examinations. It brings subject-wise study material, current affairs, search, and bookmarks together in a clean and easy-to-use interface.

---

## ✨ Features

- 📚 **Subject-wise Notes** — Organized study material for major competitive-exam subjects.
- 🔍 **Smart Search** — Quickly find subjects, notes, topics, and keywords.
- 🔖 **Bookmarks** — Save important notes for quick revision.
- 📰 **Current Affairs** — Organized current-affairs categories for exam preparation.
- 📖 **Note Viewer** — Read notes with important points and exam tips.
- 📊 **Dashboard** — Quick overview of subjects, notes, current affairs, and bookmarks.
- 📱 **Responsive Design** — Works smoothly on desktop, tablet, and mobile.
- 🎨 **Modern UI** — Clean cards, animations, responsive navigation, and student-friendly design.
- 💾 **Local Storage** — Bookmarks are saved directly in the user's browser.
